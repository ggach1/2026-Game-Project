# 움직이는 발판 연결

현재 구현은 KMJ TargetMoveObject와 CUH FallingGround처럼 Transform으로 이동하는 Collider2D를 대상으로 합니다. 다른 팀원의 스크립트 참조나 수정은 필요하지 않습니다.

- 발판 Collider2D 오브젝트를 Ground 레이어로 설정하고 Is Trigger를 끕니다.
- Collider 또는 그 부모 Transform을 이동시키면 PlayerGroundSensor가 지지면을 잡고 PlayerMotor2D가 이동량을 반영합니다.
- 발판 위에서 직접 걷는 속도와 운반 이동량은 분리합니다. 운반 자체는 달리기 파라미터를 증가시키지 않습니다.
- 점프 시 발판 연결을 즉시 해제합니다. 발판의 관성은 물려받지 않습니다.
- 사망/리스폰, 모터 비활성화, 발판 삭제/비활성화, 중력 방향 변경 시 연결을 해제합니다.
- 한 물리 틱의 이동량이 Max Platform Step(기본 0.75)을 넘으면 순간이동으로 간주하고 따라가지 않습니다. 프레임 지연으로 Transform 이동량이 커져도 동일하게 적용됩니다.
- 운반 경로를 Rigidbody2D.Cast로 검사해 벽/천장 앞에서 운반을 제한합니다. 압사 판정과 레벨 리셋은 포함하지 않습니다.
- 동적 Rigidbody의 충돌에 의한 운반, 회전 발판의 플레이어 회전, 고속 이동 및 압착 상황은 별도 Play Mode 검증과 정책 결정이 필요합니다.

## Play Mode 확인 절차

1. Ground 레이어의 비트리거 BoxCollider2D 발판을 좌우로 이동시킵니다. 플레이어가 입력 없이 함께 이동하고 Idle을 유지하는지 확인합니다.
2. 상하 이동에도 탑승이 유지되는지 확인하고, 발판 위에서 좌우로 걸어 가장자리를 벗어나면 떨어지는지 확인합니다.
3. 탑승 중 점프합니다. 발판에 끌려가지 않고, 점프 직후 다시 점프할 수 없는지 확인합니다.
4. 두 발판 사이를 이동하고, 이전 발판의 이동이 더 이상 반영되지 않는지 확인합니다.
5. 탑승 중 F8로 사망/리스폰합니다. 시작 위치로 돌아간 뒤 이전 발판에 끌려가지 않는지 확인합니다.
6. 발판을 비활성화/삭제하거나 큰 거리로 순간이동시킵니다. 플레이어가 함께 순간이동하지 않는지 확인합니다.
7. 운반 경로에 벽과 천장을 배치합니다. 운반 이동이 장애물 앞에서 제한되는지 확인합니다. 압착 시 사망은 아직 구현 대상이 아닙니다.

컴파일 확인과 실제 물리/애니메이션의 Play Mode 검증은 별개입니다. 위 절차는 수동 확인용이며 자동 실행된 테스트가 아닙니다.
