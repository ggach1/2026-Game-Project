# 탈출구 연결

CIW_TestScene 오른쪽 (7, -1.5)에 ExitDoor 프리팹을 배치했습니다. Play에서 문에 닿으면 플레이어가 사라지고 문 테두리가 초록색이 되며 Console에 탈출 완료가 출력됩니다. 편집 모드에서는 문 위치를 Gizmos의 청록색 사각형으로 표시합니다. 실제 문 그래픽은 실행 시 생성됩니다.

- 출구 Trigger 안에서 접지 상태이며 문 중심과의 가로 거리(문 로컬 좌표)가 Center Tolerance(기본 0.2) 이내이면 자동 입장합니다. 공중/가장자리 접촉으로는 입장하지 않습니다.
- EnteringExit 상태에서 입력/물리를 잠그고 시각 오브젝트만 문 중심으로 이동하며 0.25초 동안 20% 크기로 축소/페이드아웃합니다. 이후 Escaped 상태와 완료 이벤트가 발생합니다.
- Entry Duration으로 연출 시간을 조절합니다. 출구 비활성화/ResetExit 또는 외부 리스폰으로 중단하면 표현 상태를 복원합니다. 입장 시작 뒤 잠금 변경은 진행 중인 연출을 취소하지 않습니다.
- 문 테두리: 청록색은 열린 출구, 회색은 잠금, 초록색은 완료입니다.
- ExitDoor.SetUnlocked(bool)로 문을 잠그거나 해제할 수 있습니다. 잠긴 문은 통과 가능한 Trigger이며 이동을 물리적으로 막지는 않습니다.
- 출구 안에서 잠금이 해제돼도 OnTriggerStay2D가 다음 물리 틱에 입장을 처리합니다.
- 완료 시 PlayerLife.State가 Escaped로 바뀌고 입력과 물리를 멈춥니다. 파편, Died 이벤트, 사망 테스트 자동 리스폰은 실행되지 않습니다.
- ExitDoor의 On Escaped Inspector 이벤트는 탈출한 Player를 전달합니다. 여기에 레벨 담당자의 클리어 UI/다음 씬 로드 메서드를 연결하세요. Player.Life.Escaped C# 이벤트도 제공되므로 같은 완료 로직을 양쪽에 중복 연결하지 마세요.
- 현재 다음 맵 자동 로드와 클리어 UI는 연결하지 않았습니다. 테스트를 다시 하려면 Play를 재시작하세요.
- 같은 씬에서 재시작할 때는 Player.Respawn(data)로 시작 위치를 먼저 복원하고 ExitDoor.ResetExit()를 호출합니다. ResetExit은 잠금 설정을 바꾸지 않습니다.

## 수동 확인

### 입구 크기 기믹

- BoxCollider2D는 접근 감지용이며, `Opening Size`는 문틀을 제외한 실제 입구의 로컬 너비/높이입니다. 노란 Gizmo가 입구 크기를 표시합니다. 감지 영역이 입구 위치와 겹치도록 별도로 설정하세요.
- 플레이어의 접지 센서에 지정된 몸통 Collider의 물리 Bounds로 검사합니다. 너비나 높이 중 하나라도 입구보다 크면 입장하지 않습니다. 같은 크기는 허용합니다(0.0001 로컬 단위의 수치 오차 허용).
- 크기 거부 시 입력과 물리는 유지됩니다. 문이 벽처럼 이동을 막는 기능은 아닙니다.
- 입장 전 Trigger Stay마다 다시 검사하므로 안에 머문 채 문을 키우거나 플레이어의 물리 몸통을 줄여도 반영됩니다. 입장이 시작된 후의 크기 변경은 진행 중인 연출을 취소하지 않습니다.
- `ExitDoor.SetOpeningSize(Vector2)` 또는 Inspector의 Opening Size로 입구를 변경하면 임시 문 그래픽도 함께 바뀝니다. 감지 BoxCollider는 자동 변경하지 않습니다.
- 문/플레이어 Transform 및 부모 Scale을 반영합니다. Visual만 축소하면 물리 몸통은 그대로이므로 입장 가능 여부는 바뀌지 않습니다. 회전한 몸통은 외접 사각형으로 보수적으로 검사합니다.
- 확인: 기본 문 입장, 너비만 작은 문 거부, 높이만 작은 문 거부, 같은 크기 허용, 부모 Scale/음수 Scale 반영, 거부된 채 문 확대 후 입장, 거부 중 이동/점프/사망 정상 동작.

### 기존 동작

1. 살아 있는 플레이어로 진입: 완료 로그 1회, 문 초록색, 플레이어 숨김/조작 차단.
2. F8로 사망한 상태에서는 탈출하지 않고 사망 리스폰만 실행.
3. 잠긴 문에 진입: 완료되지 않음. 안에 머문 채 잠금 해제: 완료 1회.
4. 완료 후 문/컴포넌트를 다시 활성화해도 자동 사망 리스폰이나 중복 완료가 발생하지 않음.
5. 레벨 재시작 시 Player.Respawn과 ResetExit을 호출한 후 다시 완료 가능.

Play Mode 시각/물리 검증은 별도로 필요합니다.
